# ipl-data-analysis
# IPL Data Analysis Using Python

## Overview
This project analyzes IPL ball-by-ball data to understand:
- Whether winning the toss affects match outcomes
- Which match phase contributes most to winning
- The top-performing batters and bowlers across seasons

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Toss winners won only slightly more matches than toss losers
- Middle overs showed the largest scoring gap between winners and losers
- Virat Kohli emerged as the top run-scorer
- YS Chahal recorded the highest wicket count

## Surprise Finding
Winning the toss provided almost no real advantage, while middle-over performance had a much stronger connection to match outcomes.
